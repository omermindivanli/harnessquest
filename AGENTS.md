# Repository Architecture Map (AGENTS.md)
This file serves as the local context map for AI agents operating inside the HarnessQuest repository.

## Directory Structure
- `harnessquest/core/`: Deterministic execution runner, context manager, and secure sandbox.
- `harnessquest/gamification/`: XP calculation and achievement badge registry.
- `harnessquest/middleware/`: LangChain adapter for mainstream agent loops.
- `harnessquest/eval/`: LLM-as-a-judge and benchmark regression testing.
- `harnessquest/cli/`: Rich terminal UI and interactive CLI runner.
- `tests/`: Golden dataset and test suites.
