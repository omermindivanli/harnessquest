## Post 2: how it works

Why a harness? An LLM without one wanders, loops and breaks things.

In HarnessQuest you build the pieces yourself:
✅ AGENTS.md as a map, not a manual
✅ A guarded sandbox (allowlist, no shell)
✅ Loop detection, fallback routing, tracing, injection scanning

Your code is executed and tested, not just read.

## Post 3: try it in 2 minutes (no API key)

```
git clone https://github.com/omermindivanli/harnessquest
cd harnessquest && pip install -e .
harnessquest-play
```

Level 1 runs offline with a built-in mock agent. Bring Ollama, OpenAI, Anthropic or NVIDIA NIM when you want a real model.
